# Support

OpenTranscribe is a community-maintained open-source project. Support is best-effort and no response time or service level is guaranteed.

## Where to ask

- Use a **bug report** for reproducible defects.
- Use a **feature request** to propose behavior or a new provider.
- Use pull requests for focused changes that have an agreed scope.
- Use [GitHub private vulnerability reporting](https://github.com/fbossiere/open-transcribe-mcp/security/advisories/new) for suspected security vulnerabilities.

Before opening an issue, search existing issues, use the latest supported release, and reduce the problem to a safe reproduction. Never publish provider credentials, MCP bearer tokens, signed URLs, private recordings, transcripts, or personal data.

## Scope

Maintainers can help with OpenTranscribe configuration, provider adapter behavior, canonical schema questions, and reproducible deployment defects. Provider account support, recorder vendor access, legal advice, and operation of third-party infrastructure remain outside project support.
